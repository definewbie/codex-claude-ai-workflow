## 原书中可直接观察到的不一致

以下是对所提供 PDF 的静态核对结果，不是经过运行验证的完整勘误。译文保留原文，不暗中修复示例。

1. **第 1 章，PDF 第 32–33 页**：子图先调用 `compile()`，随后才向其 builder 添加条件边；展示顺序如此，不能将片段直接视为经验证的完整程序。
2. **示例 1-12，PDF 第 48–49 页**：使用了 `cfg_branch`，但所展示的章节代码未给出它的定义，也未展示将原线程上下文复制到新线程的步骤。
3. **ReAct 输出，PDF 第 72–73 页**：观察结果的 JSON 本身被截断，最终答案中的 `**` 标记未闭合。译文在文本代码块中保留该输出，并加以说明，避免影响后续 Markdown 排版。
4. **示例 2-15，PDF 第 78 页**：返回类型列出 `"b_call"` 和 `"b_propose"`，而修订路径实际返回 `goto="b_gate"`。正文还提到可以“拒绝”，但该示例仅列出 `approve`／`revise`。其中的 `schema` 是传给中断的载荷，展示代码没有另列运行时模式校验逻辑。
5. **示例 2-22，PDF 第 87 页**：`make_supervisor_node` 标注返回 `str`，实际返回内部定义的函数 `supervisor_node`。

本次只恢复可确定的排版，不把上述问题改写成新的实现。原书明确省略的完整代码仍应通过其配套仓库查阅。
