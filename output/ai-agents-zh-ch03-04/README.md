## 来源缺损与可观察的不一致

以下来自所提供 PDF 的静态核对，不是运行验证后的完整勘误。

1. **表 3-3，PDF 第 111 页**：最右侧“优化单位”列被裁切。保留可见文本片段，附原页截图。
2. **表 4-4，PDF 第 162 页**：右侧模型列被裁切，可能还有整列不可见。可见列名残片为 `Mod… (bas…`，不能由此恢复完整表头。正文提及的 NeoBERT 列在页面中不可见；译文未补造该列。
3. **表 4-5，PDF 第 173 页**：工具列被裁切。保留可见片段并附原页截图，没有用后续示例推测替换原表。
4. **第 3 章标题“为什么绝对评分更容易”**：原文如此，但该节正文强调相对比较更容易。保留标题并注明不一致。
5. **表 3-5 的长度归一化写法**：原表为 $o_i^{-1}$，前文公式则为 $1/\lvert o_i\rvert$；两处均按原文保留。
6. **示例 3-9**：原书的 `try:` 没有对应 `except` 或 `finally`，片段无法通过 Python 语法解析；同时创建了空的 `messages_and_choices`，未展示填入消息的步骤。
7. **示例 3-12**：原页将 `await model.train(...)` 放在外层循环之外；片段未展示 `finished` 到 `judged`／`hybrid_groups` 的衔接，也未展示 `max_steps` 的止损判断。
8. **示例 3-18**：初始分支调用两次 `initial_generation()`，返回状态与分数来自不同调用；改进分支的第二个返回值是父节点分数。代码按原样保留。
9. **第 4 章 RoPE 示例**：使用 ModernBERT 模型名与生成接口，而前文将该类模型定位为不生成文本的编码器；片段也未展示“32K 扩大至 128K”所需的原始配置。模型名、调用与说明均保留，并就地注明。
10. **原书展示的输出片段**：有使用单引号但称作 JSON 的输出、未闭合的内层 Markdown 围栏，以及明确截断的分析师输出。均放在完整的外层文本代码块中，避免影响后续排版；未伪装成完整可解析数据。
