# Analyze → Modify → Review → Reflect → Analyze

主 agent 自查，未启动 reviewer/额外 agent；独立判断留给用户 CC。

1. Analyze：定位 grammar/prompt/acquirer 与 wire/reader；先记录 transition、SoT、写序及退出。只修未来合法状态，不 backward recovery/single-case rescue。
2. Modify：五个原生产类内增量；没有新 class/schema/服务/锁/权限/路由规则。两个既有测试族新增合法/拒绝成对，完整族回归承接兄弟。
3. Review：读增量逐项核 unknown-key 仍拒、诊断不复制 raw 值、仅一次 correction、parse/validator 不宽松、reader 真坏帧不可洗白、原 shared 严格出口及 SHA 不变。observer 同型缺口仅复制候选，不改历史。
4. Reflect：第一次真实材料重放暴露单行 {id,text} 也属正文。候选不能因测试中的正文只包含多行碎片就自证；补更完整形状识别与真实同型测试，终止早期全回归，重新独立 clean。测试作者初次错误重载与该候选误分类分列，均不冒称生产先红。
5. Analyze：当前证明只限离线提示/诊断/分类链；第六旧 raw 仍不合法、旧账本不改，真实模型能否按新提示正确修正与后半主链仍未知。未来 Gate 需重核新发行、实际装配/配置、当前 subject/出口、observer 与预算，再获用户运行批准。

ROI：本次没有扩大到通用纠错器/协议修复器、连接代平台、原生实验或旧例迁移；只读材料复用提升证明密度。没有出现需要改变受审范围的成本收益偏差。

第二次全回归期间的只读自查另发现 version 使用旧 text helper 会将数字2.0强转成字符串；新混合帧入口改为显式字符串类型核验，与observer同向，补数字版本反例。该轮主动中断，不拼成最终凭证；变更仍限原wire语法owner，未改权限或路由。

材料压缩：中断轮仅保留真实日志、退出状态、开跑源码身份；不把尚未轮到模块的陈旧target报告复制为本轮证据。最终聚焦目录只收实际执行七套，收口数字只取最终clean各模块XML。
