# D04 原生内部委派：设计修订说明

2026-09-29。用户已明确同意本方向并要求继续；本次只修订设计与必要验证清单，没有运行 native/provider/子代理/探针，没有产品或 Rust 实施。D04 仍 DESIGN GAP；修订待独立复审。

## 当前规范与变化

规范入口是详设 §8.21；R3 I3 只作原则说明，主清单仍是唯一工作索引。本文件解释差异，不建立第二份工作清单。

从“Dual 必须禁止原生内部委派”改为“Dual 管领域流程与授权，原生客户端可组织同次执行内子任务”。内部子任务不能成为新 Dual node、独立 reviewer、批准主体或交付决定者，不能借其他 session/workstream 的权限。Claude Code 作者／Codex 评审保留；不要求为对称性开放 Claude 不必要的子任务工具。

撤掉的前置：collaboration 必须消失或全部被拒绝；Dual 独占原生子代理数量；新增逐子任务 Dual 账本；绝对零超支。保留的前置：实际权限上限、禁止提权及跨任务借权、有效作者/评审/批准与证据、未知结果安全恢复。usage/金额未知仍须如实记录，不允许以顶层值冒充含全部子调用的总量。

原生 spawn 本身现在是设计允许的内部活动，前提是所处执行已满足权限资格。不是所有已有线程都获得操作授权。native 临时日志/状态的写入仍须归入已审定 runtime/scratch 及实际 writer，不能借“内部活动”豁免产品/control/policy 路径。

## 完整链与六维自查

详设 §8.21 表覆盖准备→dispatch→内部委派→最终产物→发布→停止/恢复→下一阶段/交付；保留 D06 写入失败与 D07 结果不明窗口。内部事件不直接变成领域路由，不从父进程退出推导全部子任务已停止，不自动重发不明执行。

| 维度 | 本轮设计落点及证据上限 |
|---|---|
| Declared by | 用户方向决定、R3 I3、详设 §8.21；仅更改内部委派许可语义 |
| Proven by | 既有父执行原生切片与子配置继承可复用；子任务实际强制未证。本轮没有新增运行 PASS |
| Consumed by | 原生引擎管理内部执行；transport/run owner 记录外部事实；资格/validator/人门/交付 owner 消费既有领域材料 |
| Enforced before | 每个子任务实际副作用前须守权限；发布/推进/交付前须守领域批准。当前只是设计义务，非 ENFORCED 声明 |
| Failure route | 权限失败、结果不明、成本观测缺失分开；沿现有 typed signal/recovery。数量未知不是权限失败，权限失败不能降为成本警告 |
| Cannot-bypass test | 合法内部子任务正向证据与越权/借权/伪造身份拒绝成对；停止/冷启动/发布失败及 inline/worker/correction 组合在原工作项内验证 |

## 主清单和冻结条件对位

- W03/T07：子任务实际权限与合法读取，角色绑定、session/模式/跨任务目标；D04 §13 当前行及 §8.5 成对证明同步。
- W02/W04：执行事实、合法作者与独立复评、原生内部结果不产生 authority；不改 D02/D05 owner。
- W05：相关执行停止/完成不明、恢复不盲重放；复用 D06/D07，不增加子任务恢复状态机。
- W06/T12：候选批准与目标 Git 交付事实不受内部自评替代。
- W08/T14：全链组合、终态/残余执行展示与实际 usage/限制覆盖。

其他九项冻结设计不据此重写；若后续绑定需要改变其字段/验收契约，须按既有 §7.1 重审受影响项。冻结前能力证明与实施后整链验收分别列在 §8.21，不能以任一替代另一。

## 防止再次做偏

本轮授权是设计调整，旧实验预算不复活。后续原生子任务实验须有新的具体 Gate/预算及允许的副作用；当前会话仍不启动额外 agent。先用已有事实设计有判别力的权限/停止验证，不再花预算验证“所有原生委派均被禁止”。不穷举任意子树，沿共享强制点说明各入口与后续 turn 的覆盖；存在真实差异才补对照。

成本目标是明确可见范围和可接受风险，不构建全量子代理监控平台。已有聚合统计可用就复用，统计未知如实登记；运行 Gate 不能省略具体预算、停止方式及剩余风险接受。无法证明实际权限或既有恢复要求时，不能以选 C 为理由豁免，也不能自动搭新监督器。

采纳 CC 对 hook 停止依据的材料 PASS；收窄“所有 adapter 候选已穷尽”为“已查候选不足、继续无定向排查收益低”。旧报告/FAIL/INVALID 与受审包不改判。当前设计、主清单和冻结表已更新，尚未经本轮独立评审。
