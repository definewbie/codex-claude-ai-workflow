## Key Architecture Decisions

### Retry Backoff

`WorkflowRuntime.attemptAutoRetry()` now sleeps after `ledger.autoRetryNode()`:
- Delay calculated by `RetryPolicy.delayForAttempt()` using exponential backoff
- Per-failure-type policies in `RetryStrategies`: RATE_LIMIT (5 retries, 3s base, 2x), SESSION_MISSING (3/2s/1.5x), etc.
- Node-level config overrides via `retry.max_retries`, `retry.base_delay_ms`, `retry.backoff_multiplier`

### Handoff.json Consumption

`completedWork` and `openRisks` from handoff.json are appended as subsections:
- `completedWork` → appended to `iteration_history` section (if present in handoff.json)
- `openRisks` → appended to `human_feedback` section (if present in handoff.json)
- Not new sections — merged into existing sections per design choice (option B)

### Profile Config Overrides

`ContextBudget` now accepts optional `configOverrides` map:
- `product_review`: `max_snippet_chars=2000`, `max_recent_agent_outputs=3`
- `architecture_review`: `max_snippet_chars=3000`, `max_recent_agent_outputs=5`
- `plan_review`: `max_snippet_chars=3000`
- Other profiles (implementation, acceptance, full): no overrides, use node config or defaults
- Lookup order: profile override → node config → default constant
