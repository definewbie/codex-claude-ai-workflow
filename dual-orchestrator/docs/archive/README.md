# Archive

This directory keeps historical engineering notes that are useful for
maintainers but should not be part of the primary reading path.

Archived files may describe older implementation attempts, failed real-case
runs, or design reasoning that has since been condensed into current design
docs. Treat the current docs index, roadmap, and design files as authoritative.

For a public release, this directory is optional maintainer material. It may be
kept locally or omitted from the published repository if the current design
docs, quickstart, troubleshooting guide, and benchmark summaries are complete.

Current archived process files:

- `engineering-retrospective.md`: internal development retrospective.
- `mvp-mainline-validation.md`: historical MVP validation notes.
- `p0-closure-history-2026-06-18-19.md`: detailed P0 closure attempt history.
- `public-cleanup-todo.md`: maintainer cleanup notes.
- `technical-debt.md`: historical debt inventory.
