## Important Context

### Memory file principle
Integration code discipline: trace the call chain to actual I/O points before writing code. Four derived rules:
1. Fixes must not introduce worse bugs — check all call sites for semantic changes
2. Understand termination conditions before writing loop/startup logic
3. Side effects must be opt-in with explicit flags
4. Cleanup in reverse creation order

### Key design decisions made this session

1. **`include_sections` overrides force old path** — backward compat for nodes that explicitly configure section lists. Governed pipeline doesn't handle `max_snippet_chars` or `max_recent_agent_outputs` overrides.
2. **`sections` in result map = profile-declared sections** — not resolved/rendered sections. This preserves backward compat with existing tests that check `sections.contains("git_evidence")` regardless of data availability.
3. **`full` profile uses `MissingPolicy.PLACEHOLDER` for requirement** — matches old behavior where missing requirement.md showed "(not available)" instead of failing.
4. **`acceptanceOutcome` omitted from handoff.json** — no reliable source in the handoff markdown template.
