# T1.1 Agent Artifact Contract + T2.2 Prompt Regression 测试

## 1. 问题

当前系统有两类静默失败风险：

1. **Agent 输出漂移** — prompt 模板声明了 decision 值域（如 `PASS|NEEDS_REVISION|BLOCKED`），但 `DualControlBlockParser` 只校验 `key:value` 格式，不校验 decision 值是否在合法集合内。合法值校验散落在 `ReviewDecisionHandler.allowedDecisions()` 的硬编码 switch 里，与 prompt 模板定义是两套独立的、可能不一致的声明。

2. **Prompt 模板变量丢失** — `AgentPromptRenderer` 用 `String.replace("{{xxx}}", value)` 做替换。如果模板引用了 `{{nonexistent}}`，只产出空串，不报错。新加模板时无法提前发现变量名拼错。

3. **Contract 定义分散** — 一个 node 的合法输出值同时存在于三处：prompt 模板的自然语言、`ReviewDecisionHandler` 的 switch、workflow edge 定义里的 `on` 值。三处没有单一真相源。

## 2. 目标

- 建立 **per-node contract registry**，作为合法 decision 值和 required key 的单一真相源
- `DualControlBlockParser` 在解析阶段就能校验 contract（不合法则 `INVALID_DECISION_VALUE`）
- `ReviewDecisionHandler.allowedDecisions()` 从 contract registry 读取，消除硬编码
- `AgentPromptRenderer` 加载模板时扫描变量，与注册的合法变量集合比对
- 测试覆盖：所有模板变量校验、所有 contract 定义与 prompt 模板值域一致性

### 3.3 ReviewDecisionHandler 硬编码

```java
// ReviewDecisionHandler.allowedDecisions() 当前的硬编码
"plan.decision"      → READY_TO_IMPLEMENT, NEEDS_REVISION, BLOCKED
"acceptance.decision" → ACCEPT, ACCEPT_WITH_NOTES, REJECT, BLOCKED
default              → PASS, NEEDS_REVISION, BLOCKED
```

对照 workflow edge 定义：
- `intake.decision` → edge on `PASS`, `NEEDS_REVISION` → 但 prompt 声明 `READY_FOR_PRODUCT_REVIEW`
- `design.decision` → edge on `PASS`, `NEEDS_REVISION` → 但 prompt 声明 `READY_FOR_ARCH_REVIEW`
- `plan.decision` → edge on `READY_TO_IMPLEMENT`, `NEEDS_REVISION` → 与 prompt 一致

**发现矛盾**：`intake.decision` 和 `design.decision` 的 edge 用 `PASS`，但 agent prompt 要求输出 `READY_FOR_PRODUCT_REVIEW` / `READY_FOR_ARCH_REVIEW`。如果 agent 严格按 prompt 输出，edge 路由会找不到匹配。当前能跑是因为 agent 可能输出了 `PASS` 而非 prompt 声明的值。**Contract registry 会强制暴露这个矛盾**，这正是本设计要解决的核心问题。

### 4.2 ContractRegistry（新增）

位置：`dual-runtime/src/main/java/dev/dual/runtime/handler/ContractRegistry.java`

单一真相源。以 nodeId 为 key 注册 contract。

```java
public final class ContractRegistry {
    private static final Map<String, NodeOutputContract> CONTRACTS = Map.ofEntries(
        // --- task nodes (agent output) ---
        entry("intake.claude_brainstorm", new NodeOutputContract(
            "intake.claude_brainstorm",
            Set.of("decision", "summary"),
            Set.of("READY_FOR_PRODUCT_REVIEW"),
            Set.of("needs_human_input")
        )),
        entry("intake.codex_product_review", new NodeOutputContract(
            "intake.codex_product_review",
            Set.of("decision", "summary"),
            Set.of("PASS", "NEEDS_REVISION", "BLOCKED"),
            Set.of()
        )),
        // ... 10 entries total, one per template
        // --- decision nodes ---
        entry("intake.decision", new NodeOutputContract(
            "intake.decision",
            Set.of("decision", "summary"),
            Set.of("PASS", "NEEDS_REVISION", "BLOCKED"),
            Set.of()
        )),
        entry("design.decision", new NodeOutputContract(
            "design.decision",
            Set.of("decision", "summary"),
            Set.of("PASS", "NEEDS_REVISION", "BLOCKED"),
            Set.of()
        )),
        entry("plan.decision", new NodeOutputContract(
            "plan.decision",
            Set.of("decision", "summary"),
            Set.of("READY_TO_IMPLEMENT", "NEEDS_REVISION", "BLOCKED"),
            Set.of()
        )),
        entry("acceptance.decision", new NodeOutputContract(
            "acceptance.decision",
            Set.of("decision", "summary"),
            Set.of("ACCEPT", "ACCEPT_WITH_NOTES", "REJECT", "BLOCKED"),
            Set.of()
        ))
    );

    public static NodeOutputContract forNode(String nodeId) {
        var contract = CONTRACTS.get(nodeId);
        if (contract == null) {
            throw new IllegalArgumentException("no output contract for node: " + nodeId);
        }
        return contract;
    }

    public static boolean hasContract(String nodeId) {
        return CONTRACTS.containsKey(nodeId);
    }

    public static Set<String> allNodeIds() {
        return CONTRACTS.keySet();
    }
}
```

**关键设计决策 — decision node 的 contract 要和 edge 定义一致，而不是和 prompt 模板一致。**

原因：decision node 消费上游 agent 的输出。`ReviewDecisionHandler` 读到 `decision: PASS` 或 `decision: READY_FOR_PRODUCT_REVIEW` 后，要用这个值去匹配 edge。所以 decision node 的 `allowedDecisions` 必须与 edge 的 `on` 值完全一致。

这暴露了 3.3 中发现的矛盾：

| Decision Node | Edge `on` 值 | 上游 Agent Prompt 声明 |
|---|---|---|
| `intake.decision` | `PASS`, `NEEDS_REVISION` | `READY_FOR_PRODUCT_REVIEW` |
| `design.decision` | `PASS`, `NEEDS_REVISION` | `READY_FOR_ARCH_REVIEW` |
| `plan.decision` | `READY_TO_IMPLEMENT`, `NEEDS_REVISION` | `READY_TO_IMPLEMENT` |

**`intake.decision` 和 `design.decision` 存在不一致**：edge 路由期望 `PASS`，但 agent prompt 声明输出 `READY_FOR_PRODUCT_REVIEW` / `READY_FOR_ARCH_REVIEW`。

**修复方案**：统一到更具体的值，即修改 edge 定义和 `ReviewDecisionHandler`，使它们接受 agent prompt 声明的值：

```
intake.decision  → edge on "READY_FOR_PRODUCT_REVIEW" / "NEEDS_REVISION"
design.decision  → edge on "READY_FOR_ARCH_REVIEW" / "NEEDS_REVISION"
```

这样 edge、handler、prompt 三处完全一致。

### 4.3 ReviewDecisionHandler 改造

```java
// Before:
private Set<String> allowedDecisions(String nodeId) {
    var decisions = switch (nodeId) {
        case "plan.decision" -> List.of("READY_TO_IMPLEMENT", "NEEDS_REVISION", "BLOCKED");
        case "acceptance.decision" -> List.of("ACCEPT", "ACCEPT_WITH_NOTES", "REJECT", "BLOCKED");
        default -> List.of("PASS", "NEEDS_REVISION", "BLOCKED");
    };
    return new LinkedHashSet<>(decisions);
}

// After:
private Set<String> allowedDecisions(String nodeId) {
    if (!ContractRegistry.hasContract(nodeId)) {
        return Set.of("PASS", "NEEDS_REVISION", "BLOCKED"); // fallback for unknown nodes
    }
    return ContractRegistry.forNode(nodeId).allowedDecisions();
}
```

### 4.4 DualControlBlockParser 增加 contract 校验路径

当前 `parse()` 只做格式校验。新增一个重载，在格式校验通过后做 contract 校验：

```java
// DualControlBlockParser.java 新增方法
DualControlParseResult parse(String markdown, NodeOutputContract contract) {
    var result = parse(markdown);
    if (!result.valid()) {
        return result;
    }
    try {
        contract.validate(result.block());
    } catch (IllegalArgumentException e) {
        return DualControlParseResult.invalid(
            "CONTRACT_VIOLATION",
            e.getMessage(),
            Map.of("node_id", contract.nodeId())
        );
    }
    return result;
}
```

`ReviewDecisionHandler.evaluate()` 调用新的 `parse(content, contract)` 而非 `parse(content)`。

### 4.5 AgentPromptRenderer 变量校验

```java
// AgentPromptRenderer.java 新增
private static final Set<String> KNOWN_VARIABLES = Set.of(
    "workstream_id", "node_id", "prompt_template",
    "ledger_path", "requirement", "context_package"
);

private static final Pattern VARIABLE_PATTERN = Pattern.compile("\\{\\{([a-z_]+)}}");

private void validateTemplateVariables(String templateName, String templateContent) {
    var matcher = VARIABLE_PATTERN.matcher(templateContent);
    var unknown = new LinkedHashSet<String>();
    while (matcher.find()) {
        var variable = matcher.group(1);
        if (!KNOWN_VARIABLES.contains(variable)) {
            unknown.add(variable);
        }
    }
    if (!unknown.isEmpty()) {
        throw new IllegalArgumentException(
            "prompt template '" + templateName + "' references unknown variables: " + unknown
            + ". Known: " + KNOWN_VARIABLES
        );
    }
}
```

在 `loadTemplate()` 返回后立即调用 `validateTemplateVariables()`。这是启动时校验，不影响运行时性能。

class PromptTemplateConsistencyTest {
    // 所有模板文件名
    private static final List<String> TEMPLATES = List.of(
        "intake-claude-brainstorm", "intake-codex-product-review",
        "design-claude", "design-codex-review",
        "plan-claude", "plan-codex-review",
        "implement-claude", "implement-claude-self-test",
        "acceptance-codex-review", "stage-claude-handoff"
    );

    @ParameterizedTest
    @MethodSource
    void allTemplatesUseOnlyKnownVariables(String templateName) {
        var content = loadTemplate(templateName);
        var unknown = extractUnknownVariables(content);
        assertTrue(unknown.isEmpty(),
            templateName + " has unknown variables: " + unknown);
    }

    @ParameterizedTest
    @MethodSource
    void allTemplatesDeclareDualControlContract(String templateName) {
        var content = loadTemplate(templateName);
        assertTrue(content.contains("```dual-control"),
            templateName + " missing dual-control block in Output Contract");
        assertTrue(content.contains("decision:"),
            templateName + " missing 'decision:' key in dual-control contract");
        assertTrue(content.contains("summary:"),
            templateName + " missing 'summary:' key in dual-control contract");
    }

    @Test
    void templateCountMatchesRegistry() {
        assertEquals(TEMPLATES.size(), ContractRegistry.allNodeIds().stream()
            .filter(id -> !id.endsWith(".decision"))
            .count());
    }
}
