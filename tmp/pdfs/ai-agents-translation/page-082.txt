There might also be occasions when you want to collect parallel inputs and
resume the graph once all of them are available. This is useful when
independent human decisions can happen at the same time, such as parallel
review of two generated text sections, separate legal and technical
approvals, or multiple analysts validating different parts of an agent’s
output before the workflow continues. In Example 2-20 you see how you
can implement this.

Example 2-20. Parallel human interrupts
class DState(TypedDict, total=False):
    text_1: str
    text_2: str

def d_h1(state: DState):
    v = interrupt({"text_to_revise": state["text_1"]})
    return {"text_1": v}

def d_h2(state: DState):
    v = interrupt({"text_to_revise": state["text_2"]})
    return {"text_2": v}

def build_graph_D():
    g = StateGraph(DState)
    g.add_node("d_h1", d_h1)
    g.add_node("d_h2", d_h2)
    g.add_edge(START, "d_h1")
    g.add_edge(START, "d_h2")
    g.add_edge("d_h1", END)
    g.add_edge("d_h2", END)
    return g.compile(checkpointer=CHECKPOINTER)

    Interrupt for first text input.

   Update state with revised text_1.

    Interrupt for second text input.

   Update state with revised text_2.

   Add both nodes to the graph.

   Both nodes branch directly from START.
