        args = tc.get("args") or {}
        tool_fn = TOOLS_BY_NAME.get(name)
        if not tool_fn:
            result = json.dumps({"error": f"Unknown tool {name}"})
        else:
            result = tool_fn.invoke(args)
        outputs.append(
            ToolMessage(
                content=result,
                name=name,
                tool_call_id=tc.get("id"),
            )
        )
    return {"messages": outputs}

     If the model chose an action at ∈A, execute the tool.

   Tool output is the observation that informs the next step.

The stopping rule in Example 2-11 is simple. If the model asked for a tool,
it must complete that effect before asking it again. If it didn’t, you’d assume
it produced a final answer. This keeps the loop predictable and avoids
orphaned actions.
