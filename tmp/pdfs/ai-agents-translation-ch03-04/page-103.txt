Table 3-1. RL learning modes at a glance

 Term        What it means

 Online RL      The agent collects fresh experience while learning. In this
                    chapter, that means generating new rollouts with the current
                    policy, scoring them, and updating from those newly collected
                     trajectories.

 Offline RL     The policy is trained from a fixed dataset of previously
                   collected trajectories. No new interaction data is collected
                  during training.

 On-policy      The trajectories used for the update come from the same
                  policy that’s being improved.

 Off-policy      The trajectories used for the update come from a different
                    policy, older model version, logged behavior, human
                  demonstrations, or another agent.

 Model-free RL  The agent learns which actions lead to better outcomes from
                    interaction and reward feedback, without explicitly learning a
               model of the environment’s transition dynamics.

 Model-based    The agent learns or uses a model of how the environment
 RL             changes after actions, then uses that model for planning or
                  simulation before acting.


The only difference is that for LLM agents this loop is in a different space; it isn’t
physical. It happens in language, thought, and reasoning. Every message, every
tool call, and every piece of intermediate output becomes part of a trajectory. A
trajectory is the full record of how an agent reached an answer, step-by-step, from
the first prompt to the final result. Figure 3-1 shows the rollout timeline and
trajectory capture, while Figure 3-2 captures the fundamentals of the RL learning
loop in a single glance: the moment where action turns into feedback and feedback
